Interface de usuário avançada construída para o controle e monitoramento operacional da Central Logística (Estrela Assistência Técnica / Midea). 

## 📖 O Desafio e a Solução (Minha História)
Como **Supervisor de Logística**, assumi uma operação que carecia de registros sistêmicos e rastreabilidade ágil. Para "arrumar a casa", meu primeiro passo foi mapear todo o fluxo e criar duas planilhas complexas no Excel (Atualização Diária e Carga Histórica) para termos o controle básico do que entrava e saía.

Porém, a operação exigia mais velocidade, alertas visuais e cruzamento de dados em tempo real. Foi então que decidi automatizar meu próprio trabalho: desenvolvi este sistema Full-Stack. O frontend foi desenhado com o conceito de *Glassmorphism* para oferecer uma experiência premium aos auxiliares e clareza absoluta nos Dashboards de Performance (SLA) para a gerência.

## ✨ Principais Funcionalidades
- **Upload Inteligente:** Leitura das planilhas base em Excel (Diária e Separação) e conversão direta para o banco de dados.
- **Painel de Execução:** Controle em tempo real da produtividade da equipe no estoque com barra de progresso.
- **Triagem e Expedição:** Sistema de mudança de status com um clique e alerta visual (verde/vermelho) de consumo de peças.
- **Dashboards SLA:** Gráficos e indicadores gerenciais baseados em filtros combinados (Técnicos, Transportadoras, Regiões e Mês).
- **Ranking Dinâmico:** Banner de alerta interativo (editável) para foco em metas de redução de pendências.
